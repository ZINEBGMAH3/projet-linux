# Projet Linux

## Présentation

Ce projet a pour objectif de mettre en pratique l'administration,
la configuration et la sécurisation d'environnements Linux avec Ubuntu Server.

Le projet est organisé en trois mini-projets progressifs suivis d'un projet final.

## Environnement

- Système : Ubuntu Server 24.04.4 LTS
- Virtualisation : Oracle VirtualBox
- Système hôte : Windows
- Réseau : NAT

## Organisation du projet

### Mini-projet 1 — Configuration d'un serveur Linux propre

- Installation d'Ubuntu Server
- Configuration du réseau
- Mise à jour du système
- Commandes Linux
- Utilisateurs et groupes
- Gestion des permissions
- Configuration de SSH
- Configuration du pare-feu UFW
- Vérification et documentation

### Mini-projet 2 — Serveur Web et base de données

- Installation d'un serveur Web
- Configuration de Nginx
- Installation de MySQL
- Configuration de la base de données
- Tests du serveur

### Mini-projet 3 — WordPress sécurisé

- Installation de WordPress
- Installation et configuration de PHP
- Configuration de MySQL
- Configuration de Nginx
- Sécurisation de WordPress

### Projet final

- Ubuntu Server
- Nginx
- Application Web
- MySQL
- Docker
- Sécurisation du serveur
- Tests
- Documentation
