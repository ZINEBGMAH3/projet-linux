# Documentation -Mini-projet 1 : Configuration d'un serveur Linux 

## 1.Présentation

Ce document décrit les différentes étapes réalisées dans le cadre du mini-projet 1 consacré à l'installation ,la configuration et l'administration d'un serveur Ubuntu Server .

## 2. Installation  du serveur 
 
Le serveur a été  installé  dans une machine virtuelle Virtualbox.

### Configuration de la machine virtuelle

-Système : Ubuntu Server
-Architecture : amd64
-Mémoire : 4 Go
-Processeurs : 2
-stockage : disque virtuel de 40 Go
-Réseau : NAT
