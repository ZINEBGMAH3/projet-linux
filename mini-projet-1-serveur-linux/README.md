 # Mini-projet 1  -Configuration d un serveur web 

## 1.Objectif

L'objectif de ce mini-projet est d'installerο configurer et sécuriser un serveur linux Ubuntu Server.

Le projet permetde mettre en pratique les principales opérations d'administration système :

-installation et configuration d'Ubuntu  Server ;
-configuration réseau ;
-configuration DNS ;
-mise à jour du système ;
-gestion des utilisateurs et des groupes ;
-gestion des permissions ;
-installation et utilisation de logiciels ;
-configuration et utilisation de SSH ;
-vérification de l'état du serveur ;
-organisation et documentation des opérations réalisées.

## 2.Environnement

-Système : Ubuntu Server
-Virtualisation : virtualbox
-Architecture : amd64
-Réseau : NAT Virtualbox
-Administration : terminal Linux
-Gestion des versions : Git
-Hébergement du projet : Github
